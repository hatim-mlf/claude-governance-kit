Builds, lints and trigger-tests Agent Skills (SKILL.md folders), taking a skill idea through trigger wording, procedure, references, scripts, checks, guard and learn layers to a shipped skill. Make sure to use this skill whenever the user wants to create a new skill, turn a workflow or repeated prompt into a skill, edit or improve an existing skill, fix a skill that never triggers or triggers too often, rewrite a skill description, validate a SKILL.md or its frontmatter, or add evals to a skill, even if they only say "make this a skill" or "why does Claude ignore my skill". Not for writing ordinary documents, slash commands without a SKILL.md, or running a skill that already exists.
