# CONTEXT.md — Project Glossary

The glossary every session, roadmap row, tracker entry and commit message names
things from. It is authoritative by construction: a reader has no way to tell a
current definition from one that drifted months ago. **A stale glossary is worse
than none** — an absent definition prompts a question and a wrong one does not.

Adding or renaming a domain concept updates this file **in the same change**.
